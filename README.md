## 🧬 Core Philosophy: "Zero-Debt Engineering"
In every project, I enforce three non-negotiable laws:

**1. 🛡️ Anti-Any Law:** 100% strict typing in TypeScript. If it's not typed, it's not safe.  
**2. 🏗️ Hollow Shell Architecture:** Clean separation of business logic and transport layers.  
**3. 🚨 Fail-Fast Systems:** Robust initialization and error mapping for 99.9% uptime.
